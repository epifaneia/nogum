## Rules for translating the HTML
- Output a new file with the SAME structure: every tag, class, id, href, data-* attribute and the order of elements must stay identical. Only human-readable text changes (including `data-jokes` if present, and text inside `<span class="flag …">`, `<span class="src">` and table headers).
- Keep turn references like `T68` unchanged. Keep numbers, percentages and dice notation unchanged (use a point for decimals only if the Spanish uses a comma for a decimal: "7,15" → "7.15"; "91 %" → "91%").
- Spanish guillemets «…» become “…”.
- Copyrighted franchise names stay as they are (they are internal references).
- Wordplay: when a Spanish pun cannot survive, translate the meaning and, if needed, adapt the joke (e.g. the Fate/"destino" pun: "not share a FATE with some lazy rulebooks out there" works in English directly).
- Parody recipe titles: translate them creatively, keeping the sarcastic tone.
- Do not add or remove content. Do not summarise.
- Validate the result with Python `html.parser` (balanced tags) and check that the list of `id="…"` values is identical to the source.
